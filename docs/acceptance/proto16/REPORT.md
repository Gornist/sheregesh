## TEST-DOC-004 — руководство RU/EN в образе

В образе `90b9b9c` каталоги `/usr/share/doc/sheregesh/manual/{ru,en}` были пусты: правило mmdebstrap
`path-exclude=/usr/share/doc/*` отбрасывало HTML при установке пакета (`dpkg -L` файлы перечисляет). Руководство
перенесено в `/usr/share/sheregesh/manual` (`978e678`), в `verify_image` добавлена проверка `doc.manual`.
На обеих платах с `4ddbcb9`: `ru/` и `en/` — `build`, `recovery`, `support`; «Версия ПО 0.1.0-dev.0 · 4ddbcb97e79f»
и «Software version …» — совпадают с паспортом `sheregesh-info`. Языки по разделам совпадают (`manual.py --check`).
