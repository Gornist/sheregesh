## Найдено

- **Пробная загрузка pi1, смешанный стенд** (pi1 `c0c509c`, pi2 ещё `40d1e09`): no-plain FAIL — старый агент блока
  слушает TCP 7444 (TLS-видеосервер); ожидаемо, исчезло после OTA pi2.
- **ctl-loss «нет видео ≤ 3 с» — на границе:** 3,2 / 3,21 / 2,68 / 2,71 / 2,77 с в пяти прогонах. При SRTP поток идёт
  отдельной службой `sheregesh-video-tx`, пауза `sheregesh-remote-net` его не останавливает; пульт гасит видео по
  потере управления (тайм-аут heartbeat 3 с), а проба читает `ui-state.json` раз в 1 с (верхняя оценка +≤ 1 с).
  Критерий REQ-SW-002 в этом сценарии фактически меряет тайм-аут heartbeat — пересмотреть критерий или способ замера.
- Без источника (MS2130 не подключён) пульт каждые ~5 с запрашивает новое поколение (`video-renew` без первого
  кадра): за 10 мин поколение дошло до 126. Поведение по контракту, но шумное — кандидат на отступ (backoff).
- `ota-check/run.py` по умолчанию пишет в `/srv/build` (владелец root на devbox) — запуск с `--remote
  /home/nick/sheregesh-ota-check`.
