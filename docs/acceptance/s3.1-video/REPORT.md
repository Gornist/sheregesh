# S3.1-VIDEO — защищённый видеоканал pi2 → pi1 (протокол)

Испытания лабораторного стенда на двух физических Raspberry Pi 4B, только синтетический `videotestsrc`. Не приёмка требований: все 82 испытания Must — NOT TESTED, релизный гейт REQ-REL-001 — **NO-GO**. Аппаратный watchdog и OTA A/B не включались. microSD не извлекались: весь код доставлен DEV deploy.

## Решение

[ADR-0011](../../adr/ADR-0011-secure-video-transport.md): RTP поверх **отдельного соединения TLS 1.3 с взаимной аутентификацией** (порт 7444), те же CA стенда, сертификаты устройств и проверка URI, что у канала управления. Вариант SRTP/DTLS-SRTP отклонён по фактам с плат: привязок `gi` нет — ключ SRTP пришлось бы передавать `gst-launch` в командной строке, а `/proc/<pid>/cmdline` читается всеми (0444); добавить `python3-gi` можно только новым образом.

Тракт: pi2 `videotestsrc 1280×720@30 → timeoverlay/textoverlay «SHEREGESH SYNTHETIC TEST PATTERN» → v4l2h264enc → rtph264pay → rtpstreampay → stdout → VideoServer → TLS → VideoClient → stdin → rtpstreamdepay → rtpjitterbuffer → v4l2h264dec → videoscale 640×360 → videoconvert RGBx` pi1. **RTP не попадает ни в один сокет** — только каналы процессов и TLS; UDP не используется.

## Найдено и исправлено по ходу

1. **Декодирование не успевало (16,8 из 30 к/с).** После `v4l2h264dec` 1280×720 цепочка `videoconvert ! videoscale` давала 14 к/с: преобразование цвета полного кадра программно. Порядок `videoscale ! videoconvert` — 89 к/с на тех же данных (pi1). Исправлено (`cca621b`), касается и локального видеотракта S2. После — 30,0 к/с декодирования.
2. **Видео не закрывалось после штатного «bye» пульта.** Агент обнулял сеанс управления по `bye` до `finally`, а закрытие видео проверяло обратное — видеосеанс жил бы без сеанса управления. Найдено тестом, исправлено до выкладки (`4d3e9b6`).
3. **Трассировщик задержек GStreamer** на конвейере с аппаратным кодером записей не выдаёт — сценарий latency первым прогоном получил ERROR ([`latency-run1-tracer-error.json`](run/latency-run1-tracer-error.json)). Заменён измерением на живом потоке (`37adc72`); кодирование на pi2 явно отмечено как не измеренное.
4. Сторож процессов вне Linux (`pdeath.py`, только Mac/CI) не передавал stdin ребёнку — исправлено для приёмника с каналом.
5. CI: `ps` без `-ww` обрезал командную строку в раннере; имя временного каталога в тесте совпало с признаком компонента вне объёма (сканер `scope` сработал верно) — исправлено.

## Безопасность видеоканала

- Доступ — только по TLS 1.3 с сертификатом CA стенда и ожидаемым URI пульта (п. 2); дополнительно — только тот пульт и тот адрес, что у текущего сеанса управления; без сеанса управления — отказ до запуска генератора (тест `test_no_control_session_rejected_and_no_sender_started`).
- Конец, обрыв или смена сеанса управления закрывают видео (п. 9, тесты); каждое подключение — новое рукопожатие с эфемерным ECDHE, ключей между сеансами нет.
- Изменённый в пути байт рвёт TLS, ничего не доставляется в декодер (тест `test_tampered_byte_breaks_tls_without_delivering_data`); не-RTP данные не пишутся в декодер.
- Резервного UDP нет: при ошибке защиты видео просто отсутствует. Пульт не принимает порт видео из телеметрии — только свою конфигурацию; к постороннему узлу не подключается.
- Сессионные ключи не покидают процесс `ssl`; в протоколах и журналах ключей нет (проверено поиском).
- SSH, heartbeat и диагностика независимы: отдельный порт и потоки (п. 14); закрытие видеосеанса не блокирует цикл `asyncio` блока.

## Ограничения

- Задержка «стекло-стекло» не измерена: нет дисплея и камеры; захват и кодирование на pi2 не измерены (трассировщик GStreamer не работает с v4l2h264enc). Измерены транспорт и приёмная часть.
- Визуальная проверка GUI **не** проводилась (дисплея нет): подтверждены только полученные и декодированные кадры RGBx.
- TCP: при потерях в сети задержка растёт вместо выпадения кадров; на проводной LAN потерь не было.
- Генератор pi2 занимает ~76 % одного ядра (программное наложение текста и цвет 720p) — для синтетики допустимо.
- Захват трафика в LAN без root недоступен; отсутствие открытого видео подтверждено сокетами плат.
