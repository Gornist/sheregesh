- **Выпуск на обеих платах:** DEV deploy `0.1.0~dev0+g68fbb0469c6c` (коммит 68fbb04, ADR-0012). Образ и OTA не менялись.

## Найдено при приёмке

Первый прогон (run-20261026-1101) — FAIL: скрипт перезапускал `sheregesh-remote-net` чаще, чем позволяет юнит
(StartLimitBurst=5 за 300 с). Шестой запуск systemd отклонил (start-limit-hit); около полутора минут блок был в состоянии
failed, затем поднялся страховочным запуском. Дефект скрипта, не кода модуля: ограничение перезапусков юнита сработало как
задумано. Исправление: `s6_jr_accept.start_guard` — не больше 4 запусков в окне с учётом запусков из журнала юнита, пауза
перед stop (до страховочного запуска); тесты `test_start_guard_keeps_within_unit_start_limit`, `test_board_starts_parses_journal`.

## Что не проверено

- Физический модуль, CRSF, радиопередача — вне S6 (`docs/hardware/RADIOMASTER-NOMAD.md`, разделы 6–7).
- F-04 (кабель Ethernet) и перезагрузка pi2 в JR-09 (`--reboot`) — по решению владельца.
- Экран пульта на физическом дисплее — только снимки offscreen (`screenshots-offscreen/`).
