# S7 — стики и кнопки с пульта на удалённый блок: приёмка на стенде

- **Дата:** 2026-10-26. **Стенд:** pi1 (пульт, 192.168.1.92) с RadioMaster Boxer (EdgeTX, USB Joystick,
  `1209:4f54`), pi2 (удалённый блок, 192.168.1.171).
- **Выпуск на обеих платах:** DEV deploy `0.1.0~dev0+ga0b7d864ff17` (коммит a0b7d86, ADR-0013). Образ и OTA не менялись.
- **Объём:** SHRG-LAB 1.4 (`rc`/`rc-state`), сторож свежести на pi2, вкладка «Управление». Радиовыхода нет.

## Найдено при приёмке

- **ST-04, первый прогон — FAIL по критерию, не по передаче.** Оси в покое дрожат на 3 единицы (шум АЦП аппаратуры),
  эхо приходит 10 раз в секунду с задержкой 12–50 мс; расхождение «пульт сейчас — эхо чуть раньше» было 2 при допуске
  ±1. Числа передаются без искажений. Критерий исправлен: допуск не меньше разброса оси за окно
  (`test_echo_rest_tolerates_axis_noise_not_more`).
- **Кнопки.** В режиме USB Joystick текущей модели аппаратуры на HID-кнопки выведен только один канал (кнопка 1);
  переключатели аппаратура отдаёт осями K5–K8. Какие органы управления попадают в кнопки, задаётся в настройках
  USB Joystick на аппаратуре.

## Что не проверено

- Радиовыход, CRSF, Nomad — следующий этап (`docs/hardware/RADIOMASTER-NOMAD.md`, ADR-0012).
