Протоколы TEST-SMOKE-P/R/S — FAIL до проверки оператора: так и задумано, PASS только при всех пунктах.

**Найдено и исправлено до этого прогона:** обе платы в сетевом профиле показывали модельные значения эмуляторов —
температура блока на пульте 55 °C при датчике 66 °C, батарея 84 % без модуля питания. Теперь `sheregesh.board`:
SoC из `thermal_zone`, питание — «нет данных». Проба связи `check_link` baseline требовала поле `power` в
телеметрии и упала на честном отсутствии — критерий исправлен (power — только с модулем питания), повтор PASS.

Пульт после 300 с без ввода: `ui-state.screen.blanked = true`, видео при этом `playing` 60 к/с, связь CONNECTED.
Защита первого касания проверяется на GUI-тесте (20/20); на плате ввода нет — физический дисплей не подключён.
