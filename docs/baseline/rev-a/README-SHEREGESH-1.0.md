# Шерегеш 1.0 — комплект ТЗ Rev. A

**Дата:** 2026-10-22  
**Статус:** техническое задание для безопасного автономного лабораторного прототипа, **не приёмочный акт**.

## Комплект

1. `SHEREGESH-SRS-1.0-Rev-A.md` — системное ТЗ и критерии приёмки, **89 REQ-ID** (78 Must).
2. `SHEREGESH-HARDWARE-1.0.md` — аппаратная спецификация и CAD-задание; размеры пульта TBD.
3. `SHEREGESH-BOM-v0.3.xlsx` — исходный BOM v0.2a с утверждёнными решениями, рисками и матрицей требований.
4. `SHEREGESH-TEST-MATRIX.csv` — импортируемая матрица REQ-ID → TEST-ID, всё `NOT TESTED`.
5. `SHEREGESH-REQUIREMENTS.json` — машиночитаемый реестр для Issue/CI-интеграции.

## Что не следует считать уже готовым

- Исторические котировки BOM (состояние предыдущего файла от 21.10.2026) не перепроверялись при выпуске этого комплекта.
- **Промежуточная учтённая сумма — 65 308,32 ₽**, включая ценовые резервы; аккумуляторы, часть органов ввода и другие обязательные компоненты остаются вне суммы.
- Протоколы испытаний нового эталона не предоставлены; `NOT TESTED` не означает, что изделие уже прошло тест.
- Не все дословные ответы №1–176 доступны в настоящем комплекте. Требования ранних решений реконструированы по ранее подготовленным сводкам; перед утверждением baseline следует сверить оригинальный журнал интервью.
- Старый исходный документ 20.10.2026 использовал RK3399/Armbian для пульта; в 1.0 выбран Raspberry Pi 4B/Raspberry Pi OS. Результаты прежних хостовых тестов не эквивалентны новым аппаратным испытаниям.
- Комплект не является документацией для эксплуатации действующего управляемого летательного аппарата.

## Порядок следующей инженерной работы

1. Назначить владельцев `GAP-001`…`GAP-013` на листе «Риски Rev A».
2. Согласовать CAD-компоновку и готовые защищённые решения питания, внести точные SKU и цены.
3. Реализовать лабораторные тесты по `SHEREGESH-TEST-MATRIX.csv` и экспорт CI-протоколов.
4. Испытать готовые корпуса, экран, автономность, безопасные конфигурационные откаты.
5. Менять статус `Stable` только когда **все Must имеют фактический PASS и доказательства**.
