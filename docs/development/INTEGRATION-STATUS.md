# Интеграция процесса разработки: 2026-10-27

## Реализовано локально

- Общая точка входа AGENTS/CLAUDE, процесс, датированный срез, передача задач и работа со стендом.
- Read-only аудит worktrees. Локальная advisory-аренда ресурсов в общем git-каталоге, с атомарным захватом,
  защитой чужого владельца и без автоматического перехвата истёкших записей.
- DEV installer: video → client, наблюдение обеих служб, откат, совместимость с образом без video-unit.
- Упаковщик: video-tx/rx через launcher. Проверка образа ловит регрессию на заводской путь.
- Проба DEV deploy: независимый состав служб роли, версии из журналов текущего InvocationID/MainPID;
  смена invocation или отсутствие доказательства — unknown, пропуск покрытия — SKIP.
- Явные профили verify и JSON/JUnit: failure/timeout/missing-command, SKIP как INCOMPLETE,
  fingerprint исходников до/после. requirements-профиль подключён к CI с сохранением отчётов.
- Три проектных Claude skills, read-only reviewer и локальный SessionStart.

## Граница готовности

Платы и образы в этой задаче не изменялись. Поправки installer и обёрток активируются только новым образом;
обычный DEV deploy их не обновляет. Нужна ограниченная аппаратная приёмка установки/отката и проверки версий видео.
Отдельно подтвердить, что GUI-журнал под PAMName сохраняет service InvocationID; иначе проба честно выдаст unknown.

Аренда advisory: прямой SSH и прежние аппаратные инструменты не проверяют её автоматически.
Для нескольких машин нужен один координатор; текущая локальная блокировка не является распределённой.
Пилот настоящего аппаратного lifecycle и численная оценка ускорения разработки ещё не выполнены.
Stop hook не включён: до пилота используется явный verify. Существующие полные тесты и release gate CI сохранены.
Проектные Claude skills не устанавливаются автоматически в другие клиенты; общая политика доступна через AGENTS.md.
