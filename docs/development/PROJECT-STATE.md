## Открытые проверки

Видео не возвращается после разрыва управления / перезапуска блока (`check_video_link` ctl-loss, restart; time-sync
§3); сценарии no-plain и sender-kill не адаптированы к SRTP. Искусственные потери/reorder, 3-часовой аппаратный прогон, GL с физическим дисплеем и glass-to-glass,
реальные USB/CVBS через tx, сопоставимая метрика задержки TLS/SRTP, оставшиеся метрики видеослужб.
Спринтовые CR/GUI-критерии не равны TEST-ID реестра; L2/L3 не равны L4.
Релизная готовность определяется текущим `reqgen.py gate`, не этой страницей.

## Известные особенности разработки

- Обёртки видеослужб прежнего образа запускают код из `/usr`; переход через launcher и учёт видео при DEV-деплое исправлены в исходниках, на платах пока не проверены.
- DEV-установщик находится в ro-образе: исправления самого installer.py начинают работать после обновления образа.
- Перед изменением платы сверяй identity, образ, DEV-выпуск процессов, слот, boot_id и состояние служб.
- В конкретном эксперименте pi2 `v4l2jpegdec` зависал на VideoCore; владелец просил не запускать его без нового решения.
  `GST_TRACERS=latency` с v4l2h264enc также зависал. Используй ограниченные прогоны и проверку журнала ядра.
- Пульт без дисплея не подтверждает визуальную работу GL на физическом экране. Не снимай неэкспонированное окно через grabWindow.
