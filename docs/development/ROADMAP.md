# План разработки до 1.0

**Редакция:** 2026-10-31 (после D8). Состояние гейта — `python3 tools/reqs/reqgen.py gate`; эта страница — порядок
работы, а не доказательства.

## Объём

Решение владельца 2026-10-31: **железо вне объёма**. Закупка (дисплей, модуль питания, вентилятор, органы навигации,
кнопка питания, материалы корпусов) — только после того, как доделана вся возможная программная часть. Из
оборудования испытываются только **видеосистемы** (DJI, аналог CVBS, Walksnail) и **управление ELRS** — тем, что уже
есть у владельца. Стенд: pi1 (пульт), pi2 (блок), MS2130, devbox.

Гейт 1.0 остаётся NO-GO, пока не пройдены проверки на железе, — это ожидаемо.

## Этап B. Видеосистемы (то, что есть у владельца)

| Система | Путь | Состояние |
|---|---|---|
| HDMI-захват | MS2130 → USB 3.0 pi2, UVC YUYV 720p60 | принято (video-gen-storm, remove-tls-video) |
| DJI (очки по USB-C) | приём сырого H.264 очков на pi2 | эксперимент в ветке `codex/dji-video-input` (`0128e89`, `cadef3a`) на истории до переписывания — перенести на v2 по смыслу, не сливать |
| Аналог (CVBS) | UVC-захват MS210x (`534d:0021`) или usbtv/stk1160 | поддержка в `videoinput` есть, на железе не проверена (`docs/hardware/VIDEO_CAPTURE_COMPAT.md`) |
| Walksnail | выход очков/VRX: HDMI → MS2130 или AV → CVBS-захват | не начато; уточнить, какой выход у устройства владельца |

Для каждой: выбор источника с пульта, `check_video_link` (session, stream, latency), «стекло–стекло» через
`g2g_latency`, поведение без сигнала и при отключении (контракт v13), запись в `VIDEO_CAPTURE_COMPAT.md`.

## Этап C. Управление ELRS

RadioMaster Nomad по CRSF на UART3 (ADR-0014, `docs/hardware/NOMAD-WIRING.md`): S8 CR-01…10 пройдены со стиками-
эмулятором. Дальше — реальная связка TX → приёмник ELRS → полётный/ходовой контроллер или стенд-приёмник: телеметрия
обратного канала, failsafe при потере связи, разные частоты пакетов ELRS, задержка «стик → выход приёмника».

## Вне 1.0, по ходу

- Критерий ctl-loss «нет видео ≤ 3 с» меряет тайм-аут heartbeat 3 с — пересмотреть критерий или замер.
- `Ingest` агента: убрать мёртвый путь attach, отображение VID-05 «starting».
- Нестабильные тесты.
- Сборка shbuild на Raspberry Pi 5 с NVMe.
- Карта pi3 и mediamtx.
