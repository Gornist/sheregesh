# Передача задачи между сессиями

Заполни блок в задаче или её отчёте; не создавай параллельный реестр требований.

```text
Цель и наблюдаемое поведение:
База: repo / branch / commit / dirty:
Рабочая копия и владелец задачи:
Файлы в собственности; общие файлы и интегратор:
Требования / ADR / версия контракта:
Критерии готовности:
Сделано (commit и поведение):
Проверки: команда / результат / окружение / артефакт / уровень:
Не проверено; причина и следующий шаг:
Стенд: владелец / ресурсы / состояние до и после / восстановление:
Текущие полномочия и их область:
Фоновые процессы и способ остановки:
```

Сообщение другой сессии подтверждает координацию, но не заменяет решение владельца.
При смене контракта сначала согласуй общие интерфейсы, затем интегрируй изменения.
Объёмные журналы сохраняй артефактом; в передаче оставляй факты и ссылки.
