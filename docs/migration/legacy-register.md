# Миграционный реестр прежней разработки (REQ-DOC-007)

Источник: ветка `archive/main-2026-10-22` (9612e9f). Решение D5: ничего не переносится автоматически.
Статусы: **verified** — подтверждено на платформе 1.0; **not tested** — допускается как идея, требует проверки; **obsolete** — не применяется.

| Элемент прежней разработки | Статус для 1.0 | Примечание |

| Питание «головы» от 6S LiPo с понижающими преобразователями | obsolete | Запрещено: только готовые защищённые изделия (REQ-PWR-001) |
