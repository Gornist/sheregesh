# Находки сканирования истории и решения (REQ-REL-011)

`python3 tools/security/scan.py history v2` проверяет шаблонами секретов (`SECRET_PATTERNS`) каждую версию каждого
файла, достижимую из ветки. Находка, для которой ниже есть строка «`<blob 12 знаков> <шаблон>`», считается
разобранной. Решения: «ложное срабатывание» (с причиной) или «отозвано и заменено» (со ссылкой на подтверждение).

| Blob и шаблон | Файл | Решение |
|---|---|---|
| `3a7fce8637a9 private-key` | `tests/unit/test_deploy.py` (2026-10-24, `d65f82e`) | Ложное срабатывание: тест `test_allowed_signers_line_refuses_private_key` подаёт строку «`-----BEGIN OPENSSH PRIVATE KEY-----\nabc`», чтобы убедиться, что подпись выпуска отказывается принимать закрытый ключ; тела ключа нет. |
