# Компоненты вне объёма «Шерегеш» 1.0

Используется в TEST-SYS-003 (REQ-SYS-003) и при ревью: перечисленное не входит в образы, пакеты и BOM версии 1.0. Включение любого пункта требует отдельной специализированной документации, независимой оценки безопасности и нового решения владельца.

## Запрещено в ПО и образах

| Класс | Признаки для автоматической проверки манифеста и кода |
|---|---|
| Протоколы и стеки радиоуправления | CRSF, ELRS/ExpressLRS, SBUS, PPM-выход, MAVLink-команды управления, Crossfire |
| Управление радиочастотными модулями и видеоприёмниками | Настройка частот VRX (RX5808 и аналоги), управление мощностью передатчика |
| Код прежней разработки | Каталоги `radio/`, `srb-head`, `srb_core`, `bridge-fw`, `sheregesh-radio` |
| Включённые радиомодули Pi | Wi-Fi и Bluetooth выключены оверлеями `disable-wifi`, `disable-bt`; 1.0 работает только по проводу |

## Запрещено в аппаратной части

- Радиопередатчики и приёмники управления, антенны, VRX.
- Самодельные аккумуляторные сборки, силовые преобразователи и коммутация высокоэнергетических источников (в том числе питание от LiPo 6S из прежнего проекта).
- Подключение к действующим летательным аппаратам.

## Разрешено

Программные эмуляторы и инертные синтетические данные из `software/emulators/`: тестовый видеопоток, эмулятор удалённого блока, эмулятор телеметрии питания, инжектор неисправностей. Эмуляторы не реализуют протоколы управления аппаратами.
