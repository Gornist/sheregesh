# Секреты в «Шерегеш» 1.0

Перечень нужен для REQ-SW-005, CFG-007 и REL-011: секреты не попадают в журналы, резервные копии, экспорты и релизные вложения.

| Класс | Где живёт | Где не должен оказаться |
|---|---|---|
| Закрытый корневой ключ подписи | Только офлайн у владельца (аппаратный токен), ADR-0005 | Нигде в репозитории, CI, образах |
| Закрытый ключ выпуска CI | Секрет защищённого GitHub Environment `release` | Логи CI, артефакты, PR-workflow |
| Ключ разработчика (dev-режим) | Локально у пользователя, на устройство вносится однократно | Резервные копии, журналы, экспорт |
| Ключи SSH (dev-режим) | Раздел data, только при включённом dev-режиме | Образы, резервные копии |
| Пароли пользователей | Хеши в /etc/shadow на разделе data | Журналы, резервные копии, экспорт |

**Канареечные секреты для тестов:** строки вида `SHRG-CANARY-<класс>-<случайный>`. Тесты размещают их во всех местах из колонки «Где живёт» (с тестовыми ключами) и проверяют их отсутствие в журналах, экспортах и резервных копиях. Продуктивные секреты в тестах не используются.

Паролей и ключей по умолчанию в образах 1.0 нет.
