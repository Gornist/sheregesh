# Сборка

Как собрать ПО и образ «Шерегеша» и подготовить пару плат: пульт и удалённый блок на Raspberry Pi 4B.
Корпуса, питание и дисплей пока не выбраны: сборка железа будет описана после выбора оборудования.

## Что нужно

- Две платы Raspberry Pi 4B, две карты microSD от 8 ГБ, кабель Ethernet между платами (или общая сеть).
- Для удалённого блока — источник видео: HDMI-захват USB (проверен MacroSilicon MS2130), камера UVC, аналоговый вход
  или поток RTSP.
- Машина разработчика с Git и Python 3.11+, машина сборки Linux x86-64 с Docker (сервис shbuild).

## Без железа: эмуляторы

```sh
tools/dev/sheregesh-emu --demo          # пульт и удалённый блок отдельными процессами, сценарий неисправностей
tools/dev/sheregesh-emu --test          # все автотесты без дисплея
```

## Образ системы

Образы собирает только сервис shbuild на машине сборки: так каждый образ проходит тесты, проверку состава
и загрузочный тест.

```sh
python3 tools/build/shbuild.py install          # один раз: поставить сервис на машину сборки
python3 tools/build/shbuild.py submit           # отправить текущий коммит, будет напечатан номер задания
python3 tools/build/shbuild.py wait ЗАДАНИЕ     # дождаться итога: PASSED или причина отказа
python3 tools/build/shbuild.py fetch ЗАДАНИЕ КАТАЛОГ
```

Устанавливать можно только образ с итогом PASSED: инструменты записи и обновления отвергают другие.

## Запись карты

```sh
python3 tools/image/flash_sd.py КАТАЛОГ/sheregesh-lab-dev-pi4.img.zst              # показать подходящие карты
python3 tools/image/flash_sd.py КАТАЛОГ/sheregesh-lab-dev-pi4.img.zst --disk diskN # записать и сверить
```

Скрипт пишет только на внешний диск и сверяет записанное с контрольной суммой. Карту с уже установленной системой
он без явного согласия не перезапишет.

## Первая настройка пары

1. Вставьте карты и включите платы. Имена систем назначаются по роли: `pi1` — пульт, `pi2` — блок.
2. С машины владельца создайте тестовый CA и выдайте платам сертификаты:

   ```sh
   python3 tools/lab-pki/labpki.py init
   python3 tools/lab-pki/labpki.py pair --console АДРЕС_ПУЛЬТА --remote АДРЕС_БЛОКА
   ```

   Ключ устройства создаётся на плате и её не покидает: на машину владельца приходит только запрос на подпись.
3. Пульт сам находит блок, устанавливает защищённый канал (TLS 1.3 с взаимной аутентификацией) и задаёт блоку время.
   Проверка — раздел «Диагностика» пульта или `sheregesh-health` на плате.
