# Обслуживание

Повседневная работа с парой плат: состояние, журналы, обновления.

## Состояние

- **Пульт, раздел «Диагностика»:** связь, видео, службы пульта и блока, события с кодами и рекомендациями.
- **Раздел «Система»:** версия ПО, слоты OTA, версия образа, режим разработчика.
- **На плате:** `sheregesh-health` проверяет службы, хранилище, питание и температуру. `sheregesh-info` показывает
  паспорт: роль, версию ПО, сборку образа, версию железа и серийный номер.
- **С машины владельца:** `python3 tools/deploy/shdeploy.py status pi1`.

Температура в диагностике — датчик SoC платы. Питание показывается как «нет данных»: модуля питания на стенде нет.

## Журналы и резервная копия

- **«Журналы» → «Выгрузить на USB»** (в Minimal — кнопка выгрузки в «Диагностике») сохраняет журнал с контрольной
  суммой; секреты в нём заменены на `[REDACTED]`.
- **«Настройки» → «Резервная копия на USB»** сохраняет конфигурацию.

На стенде вместо USB-накопителя — каталог `/var/lib/sheregesh/usb` пульта.
Журналы служб на плате: `journalctl -u sheregesh-console`, `-u sheregesh-remote-net`, `-u sheregesh-video-tx`.

## Настройки

Каждое применение создаёт новую ревизию конфигурации. Службы проверяют её, и при ошибке автоматически
возвращается прежняя ревизия. Действия, меняющие устройство, выполняются только после отдельного подтверждения.

## Обновление приложения

Код приложения без системных изменений обновляется подписанным выпуском, без перезаписи карты:

```sh
python3 tools/deploy/shdeploy.py deploy pi1        # затем pi2
python3 tools/deploy/shdeploy.py rollback pi1      # вернуть предыдущий выпуск
python3 tools/deploy/shdeploy.py factory pi1       # вернуться к коду образа
```

## Обновление системы (OTA A/B)

Новый образ записывается в неактивный слот. Рабочий слот при этом не меняется.

```sh
python3 tools/deploy/shdeploy.py ota-build --image ОБРАЗ --build-report build-report.json --out ПАКЕТ
python3 tools/deploy/shdeploy.py ota-install pi1 --payload ПАКЕТ/*.shota --sha256 SHA
python3 tools/deploy/shdeploy.py ota-enable pi1
python3 tools/deploy/shdeploy.py ota-tryboot pi1   # однократная пробная загрузка нового слота
python3 tools/deploy/shdeploy.py ota-confirm pi1   # подтвердить после проверок
python3 tools/deploy/shdeploy.py ota-disable pi1
```

Обновляйте платы по одной, пульт первым. Если пробная загрузка не прошла проверки, плата сама возвращается на
прежний слот.
